# 同梱フォント

NotoSansMono-Regular.ttf はコマンド表示用の等幅フォント。公式取得元：
https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSansMono/NotoSansMono-Regular.ttf

取得日：2026-10-09。ライセンスは同梱のLICENSE-NotoSansMono.txt（SIL OFL 1.1）。著作権情報はフォント内部のnameテーブルとライセンスファイルを保持する。フォントファイルは未改変。実際の版とSHA256は生成時の検証記録に記載する。

日本語本文用フォントは同梱していない。実行環境のNoto Sans JPなど、OFLメタデータを持つ日本語フォントを指定する。Notoの公式ライセンス説明：https://github.com/notofonts/noto-docs/blob/main/docs/website/use.md
