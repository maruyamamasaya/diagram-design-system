# 図解修正プロンプト

```text
このリポジトリのAGENTS.md、共通ルール、対象テンプレートを読み、既存図解を修正してください。
prompts/generate.mdの「図解の制作方針」を適用してください。rules/quality.mdの見直しと効率化を適用し、安易な定型図で済ませず、不足情報を根拠付きで補って、情報量と分かりやすさを両立してください。保持すべき情報・条件と明示された修正範囲を守ってください。

対象ファイル・入力版：<編集元と元入力>
表現モード：<通常モード / グラフィック版。未指定なら既存を継承>
修正目的：<解決したい問題>
変更内容：<対象要素ID、変更前→変更後>
保持すべき情報・条件：<項目>
補足の採否：<rules/content.mdの基準で、残す・削る・図へ統合を項目別に判断。二重説明を作らない>
追加情報の根拠：<出典、対象版>
希望出力形式・サイズ：<指定がなければ既存の指定を継承。既存も未指定なら共通標準>

プレゼンの表現モード切替ではprompts/presentation.mdとdocs/presentation-graphic-mode.mdに従ってください。
元入力、図中要素、検証記録を照合してください。Agent Creation Modeを標準とし、元の生成モード・描画手段・共通設計を確認して適合する手段を選んでください。既存JSONエンジンへの移行を必須にせず、全手段へ共通ルールを適用してください。画像しかなく編集構造を復元できない場合は、その制約を明示してください。
明示されていない内容変更を避け、修正による接続・分岐・比較条件・ページ間参照への影響を確認してください。
元ファイルを保持し、rules/export.mdとrules/storage.mdに従って同じ図解IDの新しい版として修正版を保存してください。元入力を変更した場合は派生形式をすべて再検証してください。
変更箇所と影響箇所を再検証し、変更概要、成果物、更新した検証記録、未検証項目を提示してください。
```

プレゼンの枚数・密度は[rules/layout](../rules/layout.md)、基本配色と公式アイコンは[rules/design](../rules/design.md)に従う。明示された制作条件を優先する。

プレゼン修正でも[内容に応じたページ設計](../rules/layout.md#内容に応じたページ設計)を適用し、変更ページと前後の構成・読み順を確認する。
図解の修正では[仕組みと関係を直接伝える基準](../rules/layout.md#仕組みと関係を直接伝える図解)を使い、箱や矢印を減らすだけでなく、対象と関係に合う表現へ設計し直す。明示された修正範囲と、適切に機能している既存の図を保持する。

プレゼンのタイトル・副題を変更する場合は[言葉選びの基準](../rules/presentation.md#タイトルと副題の言葉選び)に従い、表現から読み取れる対象・範囲を本文と照合する。明示された名称や変更範囲を優先する。
