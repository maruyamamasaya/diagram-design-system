# 説明用入力：Linux学習ロードマップ

- 目的：初学者が学習段階と到達点を把握する。
- 読者：Linuxに初めて触れる人。
- タイプ：Roadmap。
- 形式：SVGとPNG。サイズ：標準。
- 前提：説明用の推奨順序。期間、ディストリビューション、必須依存は指定しない。

|ID|段階名|目的|関連項目（原文維持）|到達条件|
|---|---|---|---|---|
|L1|基本操作|現在位置とファイルを確認する|pwd / ls / cd|現在位置と移動先を説明できる|
|L2|ファイル操作|ファイルとディレクトリを扱う|mkdir / cp / mv|各操作の目的を区別できる|
|L3|権限の理解|アクセス権を理解する|chmod / chown|権限と所有者の違いを説明できる|
|L4|プロセスの理解|実行中の処理を確認する|ps / top|プロセス一覧を確認できる|

関係：L1→L2、L2→L3、L3→L4。意味は説明用の推奨学習順序。必須の技術依存を意味しない。全項目と前提を保持する。外部資料は未指定。
