# Linux Roadmap：入力例

[input.md](input.md) はテンプレート利用のための説明用入力であり、唯一の学習順序を主張するものではない。実行コマンドや技術仕様を網羅した教材ではない。

[validation.md](validation.md) は初期構築時の未実施ひな形として保持する。Phase 2では [input.json](input.json) をCLI入力に使う。最終検証ケースの成果物は `outputs/linux-roadmap-final/` に保存し、実施結果は [phase2-validation.md](phase2-validation.md) に記録する。新しい生成結果は別のoutputsサブフォルダーへ保存する。
