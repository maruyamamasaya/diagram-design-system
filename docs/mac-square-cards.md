# Macの正方形カード

2026-10-19本人依頼。iOSと同じく、資料とまとめのカード全体を1:1にそろえる。SquareBookCardを双方で共用し、タイトルは最大2行・短い場合も2行分の高さを確保・長い場合は末尾を省略。サムネイルは残り領域へ全体表示する。元の画像/資料名は変更しない。

既存のサイズスライダーに合わせて全カードが同じ列幅へ適応する。端末間の絶対pt幅を固定する仕様ではない。複数選択・ドラッグ・右プレビュー・素材テーマは既存のまま。

検証・アプリ更新の結果は作業記録 `sessions/2026-10-19-mac-square-cards.md` に記載する。
