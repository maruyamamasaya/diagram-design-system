# Mac・iOSで共通にする本棚の操作

2026-10-19本人指示。特にMacの入口が分かりづらいという指摘を受け、S3専用化と合わせて整理した。実機への配布・手操作確認は後日。

## 共通の順番

1. 本棚：プレゼン資料／図解ライブラリを切り替える。MacとiOSとも初期はプレゼン資料。
2. すべて／未整理：選んだ資料種類の中を探す。
3. フォルダ：分類先を選ぶ。階層はパスの繰返しではなく字下げで表し、全文パスはアクセシビリティに残す。
4. ゴミ箱：移動済み資料の復元・完全削除。既存の確認/削除通知契約を再利用する。
5. 本棚を管理：フォルダ作成、図解のまとめ作成、ログイン/整理同期など。同期の検証は「詳細」内に置く。

Macは「まとめ」をサイドバーにも出していたが、この重複を撤去。iOSと同じく図解一覧のカードから開く。まとめ自体や所属・読む順番のデータは保持。Macのまとめ内の編集/解除と前後移動も維持する。

「フォルダ」は資料の分類、「まとめ」は読む順番を持つセットであり、サイドバーではフォルダ、一覧では資料/まとめカードを扱う。

## 操作を置く場所

- 左：資料の種類、一覧/分類先、ゴミ箱、管理。
- 一覧上部：現在の場所、検索、グループ/タグの絞り込み、並べ替え/選択。
- Mac右：選んだ資料のプレビューと形式取得。Macカードはサムネイルと最大2行タイトル中心。
- iOSスマホは種類選択を薄い本棚バーに置き、iPadは左の本棚に置く。狭い画面への適応であり分類や意味は共通。

Macの上部から同期/検証/フォルダ管理の重複ボタンを外し、通常の更新と外観のみ残す。iOSも上部の管理メニューを左下に集約し、上部は探す操作を中心にする。
