# Mac・iPadの左本棚統合

2026-10-19。本人が画面案を承認し、既存資料一覧を活かし本棚・フォルダ・ゴミ箱を左側へまとめるよう指示。

Macは本棚の見出し、常設フォルダ、まとめ、通常の選択先としてのゴミ箱を同じサイドバーに配置。ゴミ箱は別シートを開かず中央で切替。保存場所は開閉式にし、本棚バーを小さくした。カード、改訂版集約、グリッド、検索、タグ、複数選択、ドラッグ、右プレビューは維持する。ゴミ箱の確認/完全削除は既存の共有実装を再利用し、狭い中央列では操作を2段にした。

iPadはCloudLibraryViewの上部folderControlsを撤去し、既存の左レールを常設。本棚内に資料種別切替、すべて/未整理、階層フォルダ、フォルダ管理、共通ゴミ箱を置く。上部は現在の場所/件数/検索/選択/管理の薄いバーにする。クラウド一覧の上部タブは左の種別切替と重複するため隠し、ログイン前とローカル資料では既存のタブを保持する。iPhoneは既存の本棚バー/左レールを維持。
