# 通常本棚への整理同期接続

2026-10-18〜19。本人の依頼で通常Mac/iPhoneを接続。資料本体は従来どおりS3または既存ローカルから読み、同期・バックアップに含めない。AWS構成の追加変更はなく、[承認済み配備と料金](organization-sync-deployment.md)を使用する。

## 接続と保護

Macの公開接続設定は`mac-app/config/organization-sync.json`からビルド時にInfo.plistへ組み込む。iOSも既存公開設定の同期フラグを有効にする。通常アプリで本人がログインし、同期画面で管理JSONの自動バックアップ→初回統合の追加/変更/解除件数と競合→確認→手動送信を行う。初回統合を確認するまで送信しない。

通常接続のcheckpoint/復元点は管理領域の`organization-sync/`へ保存し、従来の`test-library-sync/`と分離する。復元は同期画面の「同期を止めてバックアップから復元」を使う。端末の管理情報だけを戻し、サーバーを空に戻さない。全端末合計5回/時を維持し、失敗時は表示された待機時刻後に手動再試行する。自動背景同期は未実装。

iOSの2つの通常クラウド画面は利用者別管理領域ごとに同じ同期キューを共有し、受信/復元後は両画面の整理情報を読み直す。HTTPS接続は既存APIの1 request/secに合わせ、同じ接続の要求開始を最低1.1秒空ける。既存の401更新・失敗待機処理は維持する。
