## 共通機能

同じアカウントを使い、比較前に本棚の種類・検索・タグ等の絞り込みをそろえて更新する。Macで資料が出ない場合は「本棚を管理 → S3へログイン・更新」を試す。

- [ ] C01 起動・ログイン：各端末でログイン後にS3の資料が表示される。
- [ ] C02 一覧の一致：同じ種類・条件で更新後、Mac／iPhone／iPadの資料と最新版が一致する。
- [ ] C03 種類切替：「プレゼン資料／図解ライブラリ」を切り替えると、対応する一覧になる。
- [ ] C04 フォルダ表示：「すべて／未整理／各フォルダ」で想定する資料が表示される。
- [ ] C05 整理の同期：検証用資料のフォルダを変更し、整理同期後に他の端末へ反映される。未整理へ戻す操作も確認する。
- [ ] C06 カード：正方形でサイズがそろい、長いタイトルは最大2行・超過分は末尾省略となる。
- [ ] C07 閲覧：サムネイルと本文が表示され、複数ページ資料のページ送りができる。
- [ ] C08 形式別取得：対応資料でPNG／PDF／PPTXを取得・表示できる。
- [ ] C09 再起動：再起動後も設定・整理情報が保たれ、オンラインで一覧を再取得できる。

## 共通ゴミ箱

不要な検証専用資料だけを使う。端末内コピーの削除確認に備え、完全削除の前に各端末でその資料を取得しておく。端末間の反映は更新・同期の完了後に確認する。

- [ ] T01 移動：検証用資料をゴミ箱へ移すと通常一覧から消え、他の端末のゴミ箱にも反映される。
- [ ] T02 復元：検証用資料を復元すると通常の本棚へ戻り、各端末で再び開ける。
- [ ] T03 完全削除：検証用資料を再びゴミ箱へ移し、確認画面から完全削除できる。
- [ ] T04 削除の同期：他の端末でも次の同期後に通常一覧・ゴミ箱から消える。
- [ ] T05 端末内コピー：削除通知の同期後、各端末のアプリ内保存コピーが削除され、再起動後も開けない。別途書き出したファイルや制作原本はこの対象に含めない。

## Mac

- [ ] M01 左サイドバー：本棚の種類 → すべて／未整理 → フォルダ → ゴミ箱 → 本棚を管理の順で探せる。
- [ ] M02 カードの大きさ：小型カードでサムネイル・タイトルが読みやすく、サイズ調整も使える。
- [ ] M03 右プレビュー：選択した資料へ切り替わり、ページ数・版・形式取得を確認できる。
- [ ] M04 S3専用：ローカル資料の登録入口がなく、S3未公開の制作資料が一覧に混ざらない。

- [ ] P02 ナビゲーション：フォルダ・ゴミ箱・本棚管理へ迷わず移動し、一覧へ戻れる。
- [ ] P03 表示：長いタイトルやスクロール時もカードの大きさがそろい、ローカル資料の入口がない。

## iPad

- [ ] I02 画面方向：縦向き・横向きでサイドバーと資料一覧が崩れず、操作できる。
